# Практична №1 — Git

1. Яку задачу розв'язує git log?
Показує історію коммітів: хто, коли й навіщо зробив зміни, якщо причина описана в повідомленні.

2. Яку задачу розв'язує git diff?
Показує, що саме змінилося у файлах: які рядки додано або видалено.

3. Яка задача залишається до заняття 10?
Об'єднання паралельних змін кількох людей — для цього потрібно вивчити злиття гілок.

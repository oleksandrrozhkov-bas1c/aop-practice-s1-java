1) Навіщо в програмуванні окремий тип для «так» і «ні»?

Для логічної чіткості коду та економії пам'яті. Булевий тип (boolean) займає всього 1 байт, тоді як використання звичайних чисел для умов потребувало б 4 або 8 байт.

2) Як сказати !(a && b) людською мовою?

За законом де Моргана це означає: «НЕ а» АБО «НЕ b». Тобто загальна умова виконається, якщо хоча б одне з двох тверджень є хибним.

3) Чим && відрізняється від &?

Оператор && — це «коротке» логічне «І». 
Якщо перша умова хибна, комп'ютер другу навіть не обчислює задля економії ресурсів процесора. 
Одиночний &  це побітове «І», яке завжди рахує обидві частини повністю.

4) Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?

Працює правило «короткого замикання». 
Оскільки x != null повертає false, лінивий оператор && миттєво зупиняє перевірку і не намагається прочитати x.name, що рятує програму від критичної помилки.

5) Як запхати 32 відповіді «так/ні» в одне число?

Використати бітову маску. 
Стандартне ціле число типу int займає в пам'яті комп'ютера рівно 32 біти, де кожен окремий біт може бути або 0 (ні), або 1 (так).

6) Що швидше: n % 2 чи n & 1?

Операція n & 1 значно швидша. 
Ділення n % 2 змушує процесор виконувати важку математичну операцію ділення на рівні заліза. 
Побітове «І» (n & 1) миттєво перевіряє лише один останній біт числа за один такт процесора.

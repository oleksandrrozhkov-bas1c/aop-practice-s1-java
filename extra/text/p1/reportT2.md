###  Задача №3 (LeetCode 258)
- **Як працює:** Програма безперервно додає всі цифри числа між собою, доки не залишиться одна цифра (від 0 до 9). 
  Замість повільних циклів використано оптимізацію O(1) через залишок від ділення числа на 9 (`num % 9`), що працює миттєво для будь-яких обсягів даних.

- **Навіщо це в житті:** Алгоритм є базою для **обчислення контрольних сум та швидкого цілісного хешування**. 
  Коли користувач завантажує важкий архів чи інсталятор софту з сервера, система присвоює йому таку фінальну цифру індетифікатор. 
  Клієнт після скачування робить автоматичну перевірку: якщо цифри збіглися то файл цілий, якщо ні, тоді дані були пошкоджені при передачі або в пакет загрузили вірус.
